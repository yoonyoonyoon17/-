# 조윤호 님 맞춤 일별 채용공고 자동 추천 시스템 🚀

**사람인 · 잡코리아 · 리멤버** 3대 채용 플랫폼에서 조윤호 님의 이력서(쿠팡 풀필먼트 Area Manager 과장 & BGF로지스 8년 2개월)를 기반으로 매일 최적의 스마트 물류/풀필먼트 관리자 포지션 10개를 선별하여 HTML 웹 대시보드로 제공하고, **스마트폰 카카오톡으로 실시간 링크를 전송**합니다.

---

## 📌 핵심 추천 및 필터링 기준

1. **엄격한 자격 요건 / 자격증 검증 (오추천 원천 차단)**
   - **실제 보유 자격증**: 물류관리사, 유통관리사 2급, 무역영어 1급, 1종보통운전면허, 건설기계조종사면허
   - **미보유 자격증 (필수 요구 시 100% 자동 탈락)**: **보세사**, 관세사, 원산지관리사, 위험물안전관리자, 지게차운전기능사(단순직), 화물운송종사자 등
2. **출퇴근 편도 30분 이내 (인천역 코아루센트럴시티 기준)**
   - 인천 중구(항동/신흥동/북항 물류단지), 연수구(송도), 남동구(남동공단), 서구(원창동/청라/가좌/검단), 부천시(오정물류단지), 시흥시(시화산단)
   - *35분 초과 지역(서울 도심, 경기 남부/동부 등) 완전 배제*
3. **연봉 기준**
   - **최소 연봉선 5,100만원 이상** (5,100만원 미만 명시 공고 탈락)
   - **희망 연봉 5,500만원** 이상 시 최고 가점
   - 회사내규/면접후 결정 공고는 과장~차장/팀장급 직책으로 5,100만~6,000만원 협상 가능한 포지션만 통과
4. **일별 엄선 10 포지션**
   - 매칭 스코어(0~100점) 순으로 최상위 TOP 10 선정

## 📱 스마트폰 확인 & 카카오톡 알림 (노트북 꺼짐 대비)

### 1) 노트북이 꺼져 있어도 스마트폰에서 웹 대시보드를 언제든지 볼 수 있는 이유
- `recommendations.html` 파일이 클라우드 정적 웹 호스팅(GitHub Pages / 클라우드 스토리지)에 배포되어 24시간 인터넷에 호스팅됩니다.
- 스마트폰 브라우저에서 카카오톡으로 전달받은 링크를 클릭하면 노트북 전원 상태와 상관없이 언제든 최신 공고를 확인할 수 있습니다.
- 추가로 제공된 `.github/workflows/daily_recommendation.yml`을 통해 사용자의 GitHub 저장소에 업로드해 두시면, **노트북을 아예 켜지 않아도 GitHub 클라우드 서버가 매일 08:00에 스스로 공고를 수집하고 카카오톡을 발송**합니다.

### 2) 카카오톡 '나에게 보내기' 1분 연동 방법
1. 폴더 내 **`setup_kakao.bat`** 파일을 더블클릭합니다.
2. 안내에 따라 카카오 디벨로퍼스(developers.kakao.com)에서 발급받은 REST API 키를 입력합니다.
3. 브라우저에서 카카오 로그인 및 메시지 전송 권한에 동의합니다.
4. 연동 완료 즉시 스마트폰 카카오톡으로 테스트 메시지가 도착하며, 이후 매일 아침 08:00에 자동으로 TOP 10 요약과 링크가 전송됩니다.

## ⚙️ 파일 구성 및 실행 방법

- **`recommendations.html`**: 매일 생성되는 반응형 프리미엄 웹 대시보드
- **`run_recommendation.bat`**: 언제든 더블클릭하여 최신 공고를 즉시 수동 갱신하는 파일
- **`run_scheduled.bat`**: Windows 작업 스케줄러에서 매일 08:00에 자동 실행하는 배치 파일
- **`setup_schedule.bat`**: Windows 작업 스케줄러에 매일 08:00 자동 실행을 등록하는 마법사
- **`setup_kakao.bat`**: 카카오톡 스마트폰 메시지 전송 연동 마법사
- **`config.py`**: 조윤호 님의 프로필, 보유/미보유 자격증, 지역 및 연봉 필터 설정
- **`matcher.py`**: 이력서 1:1 매칭 엔진 및 자격증/거리/연봉 스코어링 알고리즘
- **`notifier.py`**: 카카오톡 메시지 전송 및 토큰 자동 갱신 모듈
- **`cloud_uploader.py`**: 스마트폰 24시간 접속을 위한 클라우드 웹 배포 모듈
